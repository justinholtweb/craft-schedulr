# Plugin Store promo images

Seven 1920×1080 JPEGs for the Schedulr listing, in the theme of the plugin's page at
[justinholt.com/plugins/craft-schedulr](https://justinholt.com/plugins/craft-schedulr).

```bash
./build.sh          # all slides
./build.sh "1 5"    # just slides 1 and 5
```

Output lands in `out/` as `schedulr-promo-N.jpg`: rendered at 2× in headless Chrome, then
downsampled and converted to JPEG in one `sips` pass. Promos are never PNG.

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover: name, tagline, icon, price badge | — |
| 2 | One notification, three channels, and the dedupe policy | `Notification::CHANNEL_*`, `Settings::DEDUPE_*` |
| 3 | A recurrence rule and its next twelve sends, with the runner state | `Schedule::FREQ_*`, the Schedule screen |
| 4 | 09:00 in each subscriber's own time zone, as UTC instants | per-subscriber time zone mode (Pro) |
| 5 | An audience built from conditions, and the three automation triggers | `Audiences` rule labels, `Automations::TRIGGER_*` |
| 6 | The per-send funnel, an A/B result and a signed click link | the funnel keys and `/schedulr/go` |
| 7 | Closing grid | — |

Every visual is a hand-built HTML mock rather than a screenshot. The labels are the plugin's own:
the condition groups and names on slide 5 come from `Audiences.php`, and the dedupe wording on slide
2 is the policy table in `docs/usage.md`. The figures (counts, rates) are illustrative. The dates
on slide 3 are a real every-other-Tuesday sequence from 6 October 2026, and the UTC column on slide
4 is correct for 13 October 2026, when New Zealand, Europe and North America are all on summer
time. Change the date and recheck the offsets.

The cover badge says **$79**. If the edition prices change, change it here as well as in the
places the `plugin-marketing-site` skill lists.

## Assets

- `assets/icon.svg` is a straight copy of `../src/icon.svg`.
- `assets/watermark.svg` is `../src/icon-mask.svg` with the fill switched to white: the bell with
  no tile, because a rounded square at watermark size reads as a grey box. It runs off the right
  and bottom edges. The dark disc you see in it is the dial, which is a hole in the bell.
- `fonts.css` is generated by `build.sh` from the two woff2 files and is gitignored.

`build.sh` checks for the screenshot file rather than Chrome's exit code, because headless
Chrome can write the image and still exit non-zero.
